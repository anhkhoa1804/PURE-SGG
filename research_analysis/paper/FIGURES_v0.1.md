# Figure Specifications v0.1

No figures are generated by this document. Any later plotting must use the listed saved artifacts and preserve the stated interpretation boundary.

## Figure 1 — Measurement/audit framework

- **Research question:** What intermediate sources can shape an apparent relation score, and where do the available controls act?
- **Source data:** conceptual synthesis of `research_analysis/paper/PAPER_EVIDENCE_DOSSIER.md`; no numerical data required.
- **Exact plotted quantity:** flow diagram: object-pair prior, geometry, appearance/context and frozen representation feed prediction; WPRD measures eligible within-pair score discrimination; semantic interpretation requires separate evidence.
- **Grouping:** stages, not experimental groups.
- **Interpretation:** separates predictive measurement from semantic claim.
- **Prohibited interpretation:** causal graph or proof that every path was empirically isolated.

## Figure 2 — WPRD historical ladder

- **Research question:** How do frozen, learned, geometry and null readouts compare under the historical endpoint?
- **Source data:** `paper_package/TABLES/readout_ladder.csv`; `runs/paper_c_representation_decoder_ladder_rerun_20260911T105648Z/result.json`.
- **Exact plotted quantity:** arm-level WPRD values for A1–A6, N1, N2; optional CI only if taken from the same artifact's defined interval fields.
- **Grouping:** readout / geometry / null arm; identify A5a vs A5b fit-protocol difference.
- **Interpretation:** historical decodability and geometry competition.
- **Prohibited interpretation:** independent model samples, causal geometry effect, semantic understanding.

## Figure 3 — Geometry input-contract failure and visibility audit

- **Research question:** What did the units mismatch do to the engineered geometry channels, and what R1 endpoint exists?
- **Source data:** geometry helper/source tracing in `research_analysis/R1_protocol_freeze.md`, test `tests/test_geometry_contract_flags.py`, and R1 status `research_analysis/R1_artifact_audit.md`.
- **Exact plotted quantity:** before/after channel values only if existing test fixtures expose exact values; otherwise schematic coordinate scale and channel collapse. Mark corrected R1 endpoint as unavailable.
- **Grouping:** historical normalized-input path vs intended pixel-scale contract; separate from model-performance panel.
- **Interpretation:** verified feature-construction contract defect; no corrected-performance estimate.
- **Prohibited interpretation:** geometry caused semantic change or corrected geometry improved/failed.

## Figure 5 — Predicate-level heterogeneity

- **Research question:** Are observed changes similar across predicates?
- **Source data:** `research_analysis/R2_per_predicate_effects.csv`.
